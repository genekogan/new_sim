# Client queue and perception contract (W4)

The source CLI imports local modules. Publish it only as the qualified self-contained Node ESM bundle; downloading source `eden-agent.mjs` alone is insufficient. Root owns the final served skill/bundle version and pins.

`openClientQueue(folder, {scope, adapter, onWake, onReceipt, onChange})` holds an exclusive fenced local lease. Scope identifies the exact world URL and Soul. The adapter supplies `send`, canonical `readReceipt`, fresh `context`, an optional `holdProfile` for actual offered timed activities, and `runPublic` for deferred public steps. No module calls a model. A saved dispatch reuses the same bounded clientRef after response loss. Server edge1 idempotency remains necessary. A terminal receipt starts the next step; a refusal or interruption retains unfinished work and wakes the mind. The runtime reconciles receipts independently of stream delivery.

`do` may contain multiple ordered body/public steps. For a mixed plan the full list, including its public prefix, is retained before any public or body effect. Execution follows that order; an admission failure at the local busy/protected reservation boundary sends no prefix. A model must not call an unretained walk queued. Independent public-only speech, consent responses and attention remain available during body/protected work; they do not replace it. Legacy nonbody endpoints lack durable idempotency: an uncertain speech/public request stops for explicit reconciliation, rather than replaying it after restart. Accepted public actions that return a receipt wait for its terminal phase. `for: "3m"` means 180 native-tick seconds, not three calendar world minutes. `until` is distinct: an offered bounded activity is renewed through real accepted native substeps until a future named event or authoritative world-clock deadline, then an owned stand request is reconciled before proceeding. Past events cannot release a later step. Unqualified holds/clock/guards refuse, with no fabricated idle hold. Renewal boundaries are real native completions, not a guarantee of uninterrupted physical posture.

`protected: true` is a local queue policy. Owner replacement requires explicit force for that step. Nonprotected replacement submits the new act through ordinary native admission and observes its waiting phase until native safe-stop completes. The queue does not invent an uninterruptible server reading flag. An attended lease pauses new queue submissions. Routine enqueue uses stable `{id, source}` and is idempotent for the current occurrence; the mounted cadence coordinator reuses qualified bindings. See CLIENT-CADENCE.md for the separate world/real clocks and review budgets.

Fresh boot initializes/rotates the cached complete gazetteer. Paged destinations require the declared `completeStaticEtag`; no page is silently dropped. Modern wakes use `here?include=doHere` and current short offers/exits. Full capabilities are fetched only explicitly/for hold qualification; edge1 fallback retains its older map/capabilities behavior. Coverage records observed canonical place IDs, never accepted walk targets or display-name place paths. It corrects unsupported blanket tour-complete statements.

Normal-origin SSE requires hello within 5 seconds and a complete frame within 35 seconds. A partial byte trickle is not healthy. Failed streams fall back to bounded wait plus canonical receipt reconciliation. Known Quick Tunnel hosts use wait directly because Quick Tunnels do not support SSE; the CLI does not currently select WebSocket delivery.

Status exposes effective settings and their sources, queue length, actual coverage, next wake/check deadline, transport reason and frame/event age. JSONL logs carry `t` (UTC), `monotonicMs`, and `runId`. `fetch` reports path/status/actual response UTF-8 bytes (no headers). `wakeStart`/`wakeEnd` report reason, session and queue IDs; wakeEnd preserves input/cached/cacheWrite/output/reasoning separately. `actSubmit`/`actVerdict` record stable refs and actual receipt IDs; `terminalReceive` records canonical terminal phase and step ID. Rotation, owner occurrence, queue completion and transport fallback are explicit events. Static boot/catalogue traffic is distinguishable by path; count all per-wake fetched paths when computing byte means.

Codex uses supported exec plus exact thread resume with the reviewed guard and `--ignore-user-config` after exec/resume. It never copies/symlinks account credentials or falls back to enabled tools. Unexpected tool items, byte limits and wall deadlines fail closed; generation guards discard old turn events. Parser help and fake-provider tests do not establish real model isolation. Subscription USD is null/unknown; ordinary subscription live remains available with unknown billing. Optional run-seconds bounds a session; zero means run until STOP/interruption. Root evaluation cohorts impose their own reviewed deadline without making it an owner onboarding requirement. Unknown token usage pauses further model calls. Requested model aliases, provider-reported resolved model, client calls, internal provider calls and OS processes are separate measures. USD/resolved model/internal calls remain unknown when not reported. ## Conversation continuity and degraded memory

The live integration consumes `client-conversations.mjs` canonical owned views/events: conversation ID, state, self role, joined members, invited/asked people, turn count and the bounded latest entitled turn. Last speaker is separate from the participant set. Refresh/reconcile and cold context preserve scope and actual consent; they do not infer membership from public directory or physical proximity. The default autonomous same-party start guard returns a local refusal rather than silently making a second group or rewriting the requested operation. Manual CLI/API semantics remain unchanged; there is no new CLI override flag. Accepted leave/new-start and renewed independent invitation decisions remain possible.

`accepted:false` from the server remains a refusal, with the code/reason and unchanged local membership. It must neither trigger post-accept speech nor complete a deferred public step as successful; public-step refusal/uncertainty stops its dependent suffix. Each independent speaker in one conversation has distinct memory evidence while scorecards still count the conversation once. A memory/judgment failure is surfaced as degraded memory, not a transport failure that permanently consumes a valid incoming event. Strict source/trust and projection-edit guards remain active; failed memory retention is never represented as successful.
