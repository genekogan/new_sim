# Runtime memory adapter (W5)

`openClientMemory(folder, {scope, now})` accepts normalized public catalogue, here frames, canonical terminal receipts, queue projections and explicit model remember selectors. It does not read HTTP headers, identity files or raw world state. A wrong world/Soul scope is refused before opening memory projections.

Code-owned markdown facts come from the append-only event fold: arrivals count actual place transitions; acceptance is never arrival; learned facts retain source and provenance; duplicate receipts/sources are deduplicated; actual produced IDs may have an undeclared location; directory membership is not an encounter. Old `endedAt.placePath` display names are labels only. W2 authored content is labelled authored fiction; Soul text is untrusted data. Explicit model judgments have separate selector-controlled projections. Schedule is owner-editable and is initialized only when absent; PERSONA/PRIORITIES are not written. Unchanged projections skip writes, while external edits conflict before appending facts and cold replay can repair projections.

Retrieval bounds self to 20 lines, goals to three, journal to eight recent entries, nearby confirmed people, current place/related attributable facts and matching lessons. A lesson requires an explicit `fixes` refused-step ID and a genuinely completed matching fix receipt. Unknown USD remains unknown. Queue markdown is a projection, not another runner or authoritative queue.

Cold restart tests exercise ten distinct attributable facts, receipt dedupe, real arrival versus accepted targets, untrusted speech separation, unknown locations/USD, owner schedule preservation, external edit conflicts, unchanged historical journal mtime and selector/path boundaries. These synthetic tests do not claim S1 cold real-model recall, six-turn dialogue or actual billing/latency qualification.

Public knowledge references are separate from admitted boot destinations. At boot the full public catalogue is fetched once for identities; only the compact admitted list informs queue/coverage. Authenticated canonical terminal facts may register additional cited public identities (world UUIDs, books, presentations, produced objects). These registrations never add a walk offer or visit. Actual here/endedAt locations, including personal mats, create observed-location rows with no walking admission; only actual arrival transitions increment visits. references.md labels this boundary. Learned facts retain all bytes up to the W2 2000-character limit, with exact source/trust in the machine log and escaped readable Markdown. Model remember cannot register public facts/references.
