2026-09-30. Branch `codex/shared-food-break`, base `340ed284`. Separately unreleased; root owns registry/index/rules and all UI/render/release integration. No shared engine, existing action, default world or pin changes.

`viewer/engine/activities/shared-food-break.ts` exports `sharedFoodBreak`, `SHARED_FOOD_ACTIONS`, `readSharedFoodBreak` and typed params/readout. Intent is `{pot, participants:[{actor,bowl,spoon,service:[x,z],returns:[{item,surfaceSlot},{item,surfaceSlot}]} ×2], at:[x,z]}`. Exactly two distinct free ground actors, their exact bowl/spoon and distinct approved return slots are required; no Mars IDs. Preflight checks actual utensil ownership/support, actor/hands/item/return-slot availability, supported shared pot and sufficient pot servings only for empty bowls. Elevated return bases and usable access links refuse. Correctly held own utensils are retained; partly filled bowls are eaten without serving again.

Parent reserves only exclusive `shared-food:<pot>` and dispatches ordinary non-preempting children: missing takes, explicit service walks/serves, actual converse formation, eating, group release, then serial stow. Children own physical resources; parent never writes poses/support/hands/food/equipment. Workstation progress/resume is untouched and remains a separate explicit owner command. External accepted actor commands and child cancellation/failure stop further dispatch; only owned children drain, preserving foreign commands and partial food/hand ownership. The fixed 180 simulation-second deadline initiates drain rather than forcing cleanup. If a child cannot safely stop, parent remains active and retains its token until actual terminal. Ordinary `hold_items` remains active when cancellation leaves supported held utensils; this is intentional ownership, not a leaked preparation claim. Readout explains remaining held cleanup/retry.

The reusable `createTurns`/`stepTurns` clock starts only for an actually talking, owned group. Floor and attention coordinates are readout only, with floor-change marks; no authoritative head/pose writes. Public floor requires at least two actual group-owned participants and an eligible current floor holder. Release/cancellation clears it. Root will derive render-only attention from this readout. Current blocked/draining owned descendants' diagnostics are surfaced. Stow dispatch explicitly waits for actual group terminal even under delayed cancellation.
