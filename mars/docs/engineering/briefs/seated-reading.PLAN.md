# Bounded seated reading — Mars MVP

2026-10-01, root-only implementation while the recovered shared-walk candidate gates.
This is required pursuit breadth, not an animation redesign or an Eden framework.

Supported intent: a free-handed ground actor approaches a real compatible chair,
reads four compressed sections of an existing flat supported book, safely stands up
on interruption, and explicitly returns to the same retained bookmark. The book
identity/pose/support never changes as a side effect of reading. Two rotated layouts
use the same bindings/capability. Generic book and participants are hypothetical;
The indexed public [Electric Lounge announcement](https://marscollege.substack.com/p/welcome-to-the-electric-lounge) describes reading books together and discussing them; it does not establish this staging.

Execution uses ordinary registered sit/walk and Runtime ownership. Reading exclusively claims
actor, chair and book, and shares stable table support with other readers. Missing capability/support, occupied seat,
incompatible facing/distance and unavailable book refuse with named diagnostics.
A moved chair/book or unavailable book stops and drains only owned physical children.
Player direction takes precedence through the existing handoff. A bookmark records
same reader/task/total duration and elapsed reading, not an arbitrary psychological
model. Active reading snapshots are explicitly unsupported; safe stop plus quiescent
JSON restoration is tested. The existing active-equipment snapshot-drop guard is
made capability-neutral so reading and computer work cannot become ownerless active.

Visual scope: current seated rig, modest bounded head gaze, supported open book,
secondary leaf motion and a visible bookmark. No rig/animation migration, new IK,
finger-contact certification or held-book reading. No universal seated-task
abstraction yet: derive one only when repeated real consumers justify its cost.

Acceptance: two physical orientations, sections/completion, identity/support,
interruption/restore/resume, player handoff, invalid bindings, availability changes,
deterministic replay; actual UI Play, fresh Step/reset and inspected runtime captures.
Then combined full gate before integration. Stop/escalate if existing seat approach
or serious geometry needs a larger prerequisite; do not loosen any test or pin.

Files: engine/objects/reading.ts, engine/scenarios/reading.ts and focused test;
small catalog/registry/snapshot guard additions; Lab scenario/HUD/hook/tour;
existing renderer item/head adapter and new browser test. Historical content and
camera policies are untouched. This worktree is unreleased and separate from the
immutable shared-walk candidate9b85793.
