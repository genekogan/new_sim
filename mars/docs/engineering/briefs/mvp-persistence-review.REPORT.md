This is a potentially wedged usable object through supported opt-in drop, distinct from deferred intention continuation. No runtime reproduction was run; a focused negative test is required before calling this a confirmed bug or checkpoint blocker.

Do not synthesize execs or reset task progress, invent active routine serialization, or weaken held-load/waiting guards.
