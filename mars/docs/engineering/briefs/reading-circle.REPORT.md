# Shared reading circle candidate

Local bounded core candidate from `6b04a8b`, isolated branch `codex/reading-circle`. This is hypothetical staging with anonymous roles and a generic supported book. Archive orientation was limited to Discord indexes and `docs/archive/events/summer-sci-fi-club-2024-w23.md`; only the general practice of reading to a small listening group informs this fixture. No historical participant, text, tabletop layout or event is reconstructed.

One reader uses ordinary registered `read_book` with one stable book ID, reader, task and total duration. Two listeners initially form real declared ground slots; an optional third can Join. Ordinary `take_slot` children hold their actual listening positions and book-facing headings before the first reading starts. Reading advances the book's real elapsed time and pages. At bounded intervals the reader safely stands up through ordinary cancellation, retaining an unfinished bookmark, then the same chair is occupied through an ordinary seated hold for discussion. Listeners take talk/listen floors through ordinary slot holds. Completed questions, answers and requested comments retain actor, actual book, page, elapsed reading time, duration and question references. The next interval explicitly resumes the same ordinary reading task rather than resetting it.

Pause drains ordinary children and retains the bookmark, completed effects and partial discussion turn. Explicit same-Runtime Resume reforms the declared places and continues the current stage. End safely releases all owned physical children and logical commitments, preserving the actual completed/unfinished book. A later new circle may explicitly resume an unfinished same-reader task. Reader direction takes precedence and exposes a named waiting reason before explicit Resume. Listener Leave dispatches an independent ordinary walk; circle cleanup never cancels that directive. Declared late Join also works while safely paused/waiting, followed by explicit Resume. If all listeners leave, Resume refuses with `reading_circle.audience-left` until a declared listener rejoins.

## API and integration

- Activity exports: `readingCircle`, `readingCircleControl`, `READING_CIRCLE_ACTIONS`, `ReadingCircleParams`, `ReadingCircleIntent`, `readReadingCircle`.
- Scenario exports: `readingCircleWorld(yaw)`, `readingCircleScene()`, `readingCircleBinding()`, `readingCircleRuntime(yaw)`. Registry extras filter already-registered verbs for future canonical wiring.
- Main action: `reading_circle`; controls: `reading_circle_control` with `{session,intent}`. Intents are Pause/Resume/End; actor-bound Join/Ask/Answer/Floor; or Leave with a declared ordinary walk destination.
- Detached readout includes actual book pose/support, retained reading facts/effects, `attentionTarget:{entity,point:[x,y,z]}`, physical floor holder, reader `{actor,role,seat,action,state}`, and each listener's actual `hold`, slot, active membership, departure and occupied listening/speaking state. The renderer can gate attention by the ordinary child's authoritative actor claim. Reading uses the existing seated reading adapter; no bespoke poses were added.

## Boundaries and verification

The existing reading model permits unfinished continuation only for the same reader/task/total duration. Reader handoff is therefore explicitly unsupported and tested as a refusal, avoiding progress reset. The book remains flat on its declared grounded table support; this is supported tabletop reading, without invented hand-held reading, pickup/tilt gestures, dialogue text, speech synthesis or a new social/anatomy subsystem. Normal seated stand-up/sit-down transitions occur between reading and discussion; fine gestures remain renderer limitations. Active save/load is deferred; session state is only supported in the same Runtime. End after completed reading does not reset or repatriate effects, and cannot restore an ended coordinator graph.
