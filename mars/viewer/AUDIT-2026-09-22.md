# Campus viewer audit — 22 September 2026

Scope: the browser viewer, modular editor, walking/animation systems, shared simulation and MCP Worker, dependencies, and Cloudflare deployment. This is a code and runtime audit; it does not establish the architectural accuracy of the source CAD or survey the campus again.

## Fixed

| Area | Defect | Change |
|---|---|---|
| GPU ownership | Model swaps/unmounts missed alternate materials, normal/roughness textures, decoded ImageBitmaps, skeleton textures, and several environment resources. Late model loads outlived their viewer. | Explicit resource ownership with deduplicated disposal, fetch cancellation, late-result disposal, skeleton-specific cleanup, and complete environment teardown. |
| Animated assets | Partial template failures and late EUC loads retained assets. Rider cleanup disposed geometry shared with other visitors. | One owner for template assets, separate ownership for helmets and cloned skeletons, cancellation and failure cleanup. |
| Materials | Studio eagerly allocated per-mesh generic materials; reconstruction display toggles allocated new materials each time. | Lazy caches shared by source material; fixed reusable reconstruction display materials. |
| Draw calls | Thousands of static editable meshes were submitted individually even in Inspect. | Spatial/material render batches, separate from original editable nodes. Picking and collision queries still use originals. Batches are rebuilt after changes and released on teardown. |
| Background work | Hidden tabs still rendered and updated controls. Room requests had no timeout or backoff. | Suspend hidden rendering and polling, bound requests to 12 seconds, abort abandoned requests, back off failed polling. |
| Layout imports | Import reset the current scene before discovering bad IDs or failed asset loads. Transform validation could throw unexpectedly or accept invalid scales. | Strict bounded schema, duplicate/unknown ID checks, unit quaternion checks, pre-load and validate every addition before committing. Rejected imports preserve the current scene. |
| Reusable components | Duplication lost edited stock dimensions; nested edits in copied assemblies were not saved; copied meshes could inherit the render-only hidden layer or generic finish. | Retain transforms and nested component transforms, validate child paths before applying them, restore source materials and render layers, cache stock assets. |
| Editor controls | Escape could commit the old input draft on blur. “Adjustable” stock had no scale controls. | Explicit cancellation, scale controls, bounded transforms, clear-selection control. |
| Exports | Export used whichever display materials were currently selected and allowed overlapping expensive exports. Browser download completion was unclear. | Snapshot editable nodes with original textured materials, omit render batches/atmosphere, serialize one export at a time, offer a persistent explicit prepared-GLB download link. Blob URLs are released when replaced or the viewer closes. |
| Shared-room races | Old polling results could overwrite newer commands; a command finishing after Leave could reconnect the scene. Pending connections did not lock layout editing. | Generation and revision ordering, immediate request cancellation and editing lock, stale-response rejection, connection lifecycle cleanup. |
| Room UX | Storage errors could prevent leaving; fragment room links were only read on mount; clipboard fallback was missing for spectators; camera shortcuts were disabled with room editing controls. | Resilient Leave, hash-change handling, visible copy fallback, disabled controls until state arrives, independent camera shortcuts. |
| Simulation math | Repeated per-frame path allocations, wrong final heading with degenerate segments, negative wrapped hours, teleport on a new wander command, stale activity membership. | Cache immutable path metrics, preserve arrival heading, positive time wrapping, start new motion at the current pose, update activity membership. |
| Navigation | Grid routes could connect to a position through blocked geometry; floor normals were wrong under nonuniform scaling; render batching could hide collision meshes from ray queries. | Validate sub-cell connectors, preserve exact accepted destinations, use normal matrices, include original collision layers, exclude reference planes/people from structural collisions. |
| Campus life | Selecting and deselecting an unchanged component rebuilt navigation/scenery and reset walkers. Leaving a remote room retained its EUC settings. Local EUC routes ignored newly moved/added structures. | Rebuild only after geometry changes, reset local rider settings on disconnect, regenerate local perimeter bounds after edits. Preserve reduced-motion choice on room join. |
| Commands | Group commands could partially mutate their caller before failing. Reusing a command UUID with different arguments silently hid the conflict. Idempotency retention was off by one. | Clone before mutation, transactional receipt fingerprints, reject conflicting payloads, retain 256 receipts, guard prototype-name lookups. Existing room storage gets an additive nullable column. |
| HTTP | Bodies were read before capability authentication, method restrictions were incomplete, weak ETag validators were ignored. | Authenticate first, enforce methods, preserve bounded body reads, support weak conditional validators. Regression coverage for ranges, HEAD, 304, 405 and 416. |
| Pages | Simulation guide inherited a clipped full-screen layout with dark-on-dark text. Comparison viewport ignored source aspect. | Scrollable readable guide, source-aspect comparison viewport, cancellation for index fetches, fullscreen error handling. |
| Scaffolding | The browser-only app carried unused Next/vinext/Sites/SSR and UI component infrastructure. | Plain Vite/React routes plus the existing Cloudflare simulation Worker. Removed 120 unused component source files, unused hooks/config, and obsolete hosting metadata. Direct runtime dependencies: 24 → 6. |
| Dependencies | Initial dependency audit reported 11 advisories, including 8 high severity. | Remove unused vulnerable dependency chains and update tooling. Final full `npm audit` reports 0 advisories (including dev dependencies), as of this audit. |
| Deployment | Generated server rendering bundle was unnecessary; HTML route handling required explicit configuration. | Small static viewer build, explicit Worker route allowlist, native MCP handler, no-cache HTML, immutable hashed JS/CSS, `html_handling: none`. Local Cloudflare runtime test caught and fixed canonical redirects before deployment. |

## Evidence and checks

- TypeScript and project lint pass.
- 28 automated regression tests pass. Added tests cover resource disposal, batching/picking, invalid and nested layout transforms, snapshot ordering, atomic commands, motion continuity, navigation connectors and streamed downloads. Existing walking/jump, camera-ground, bilateral human mesh and EUC tests remain in the suite.
- Actual Streamable HTTP MCP handshake and all ten tools pass against the isolated development server and built Worker. Authentication, spectator restrictions, room isolation, pause/resume, invalid camera positions, command idempotency, rollback and request limits are exercised.
- Production build and Wrangler dry run pass. HTTP smoke tests check both forms of app routes, no-cache HTML, referenced entry assets, unknown-route 404, anonymous API denial, wrong-method 405, and the actual GLB range header.
- Browser checks exercised selection, Escape cancellation, resizing and duplication, invalid then valid layout import, room creation/pause/Leave, cutaways, generic/source materials, and the production-built viewport.
- Observed Chiba-view draw calls: about **4,756 unbatched → 1,294 batched** (approximately 73% fewer). This is a draw-call observation on this machine, not a claim of a 73% frame-rate gain. Editing still renders original components individually.
- Production-browser export preparation completed with a **124.2 MB editable GLB** and an explicit download link. The in-app browser did not emit the automated download event, so filesystem delivery is not asserted by the browser test.
- Pre-edit source backup: `.cloudflare/audit/code-before.tgz`. Test/build/audit receipts are under `.cloudflare/audit/`; these are not published. No original media or model deliverables were rewritten.

Browser verification uses the available in-app browser control. The repository did not have the optional standalone e2e harness; no claim is made that that harness ran.

## Remaining scope and limits

The 126.9 MB campus GLB and its textures remain the largest cold-load and memory cost. Geometry and source textures were preserved; compression/LOD requires its own visual accuracy comparison. This pass is not a long-duration heap soak test or a guarantee that every possible leak is absent.

Navigation remains conservative ground-level routing over the replica, not a complete indoor/stair navigation mesh or physics engine. Shared routes do not implement pedestrian collision avoidance. Room capabilities are bearer invitations; leaving does not revoke old invitations. Account-based access, invitation revocation, retention policies, and per-user quotas are separate product features, not silently introduced by this audit.

Rooms continue to use the baseline layout. Local JSON layouts preserve edits and reusable components; they do not constitute a verified materials inventory. Existing accuracy caveats remain visible.

References consulted for deployment behavior: [Cloudflare Workers best practices](https://developers.cloudflare.com/workers/best-practices/workers-best-practices/) and [static HTML handling](https://developers.cloudflare.com/workers/static-assets/routing/advanced/html-handling/).
