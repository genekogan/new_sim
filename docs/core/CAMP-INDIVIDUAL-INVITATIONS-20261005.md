# Bounded individual supper invitations

The original camp pack creates supper with four card steps plus one invitation
per other resident. With eight residents the frozen producer emits eleven steps,
exceeding the actual card schema's eight-step bound. Earlier host cards also keep
their original recipient list when later Souls arrive; preserving their hashes
means a new guest cannot simply be inserted into their recorded definition.

The pack now offers a separate ordinary card for inviting each known peer to a
meal gathering the actor actually hosts. Its single effect is the actor's own
`say/invite`. It grants no attendance, moves no guest, changes no guest intent or
ownership, and does not reserve their body. Existing speech expiry suppresses an
immediate repeat. A peer whose canonical Soul is gone, another person's gathering or a peer
already attending does not satisfy its preconditions. Recipients can continue
their current purposes or independently choose an existing joining activity.
The target gathering and recipient are explicit canonical IDs; bounded readable
names plus a pair digest distinguish invitations without requiring a new verb,
kernel operation, scheduler, timetable or wire schema.

New host recipes with more than four peers open the gathering with the original
four host steps; invitation choices follow independently. New recipes for casts
of five or fewer retain the exact original recipe. Previously minted host cards
are never rewritten, whatever the later population. Population refresh adds new
peer invitations to existing decks using the existing logged mint path. The
native approach and rest/join controllers are unchanged. These are sequential
choices, not a new concurrent motion/communication composition controller.

The affected tests cover the exact old producer's eight-resident schema failure,
eight actual local invited owners/native bodies, all eight new bounded host
recipes and 56 invitation cards, original four-host hash equality, and a later
guest's new invitation without history changes. The old invalid recipes are
observed through a detached queue spy, never submitted to the native log.

The native owned probe accepts explicit legacy card agendas from Alice's actual
local owner endpoint, then uses labelled selected fixture decisions. Alice walks
more than 20m before opening supper, invites only Eve, and the invitation leaves
Eve's body, intent, pending program, ownership and attendance untouched. Eve's
own different owner subsequently supplies the joining agenda; Eve independently
walks more than 20m and plays one native join. An invitation is not that later
choice. Native violations and paid spend are zero. Actual snapshot and genesis
match engine/kernel with the existing durable clock frontier installed in this
fixture. Full synthetic private causal events retain seq/tick/author, owned body
IDs, original/final positions and both reconstruction hashes.

Failures are retained: the first fixture passed minted metadata into the strict
recipe-only schema and lacked an explicit owner agenda in the normal bounded
option list. After those fixture corrections, snapshot matched but genesis could
only recover the last logged-event tick, earlier than native completion. Enabling
the existing durable frontier proves recovery of the real completed head; the
assertion still compares full hashes. A diagnostic snapshot comparison did not
change production code. Initial type invocation omitted strict mode required by
the repository; a later trace field used `by` instead of canonical `author`.
Both invocation/fixture corrections are recorded separately from runtime fixes.

Affected camp/invitation/living suite: thirteen PASS. A later trace-author
correction passed its focused native recheck. Final 64-bit pair-name hardening
passed nine invitation/camp checks and strict scoped server types; unchanged
living checks are reused.
Exact receipts and proof pins are in the team handoff audit, not a claim that all
historical failures passed. The synthetic trace is private test evidence and must
never become a public take or recording.

This removes a card-size obstacle to the approved eight-Soul Mars program. It
does not complete that program: only the existing four personal mat/utensil sets
are present, and missing resources remain explicit. Eight-person meal service,
ordinary-language compiler/autonomous choices, invitation hearing/range realism,
generated dialogue, the expanded physical layout, upper-floor/stair support,
mat top contacts, artificial water, material bills/recovery and World rendering
need their own evidence. No immutable C194 supplier, default bootstrap, production
policy, main or release is changed.
