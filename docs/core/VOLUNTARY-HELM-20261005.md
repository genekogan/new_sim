body/boat reservations. There is one holder. Native start only reserves; the
actual native step acquires/releases. Cancellation before that step grants
nothing. Another passenger cannot release the holder's capability. The fresh
adapter also refuses an explicit foreign `actor` on board/leave/travel/helm

Leaving revokes this actor's helm capability. Retirement revokes it immediately
while retaining occupied physical bodies until the real supported exit. Retiring
at an away dock can remain pending indefinitely without a permitted pilot
return. It never forces a return, assigns a replacement pilot or cancels another
owner's trip. Seated/underway cleanup and permission are separate.
