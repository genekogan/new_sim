# Existing activity coverage in closed steering

Source opt-in for T100/G384, not activated in main or the current Root.
IntentControlV2 requires both closedGoalsV1 and registeredActivitiesV1. Its
owner control advertises human-capabilities/2; a default closed service still
advertises /1 with only the five original goals. V1 registry data explicitly
refuses an activity goal. The same intention endpoint and request/authority
mechanism remain in use; there is no legacy compiler fallback.

V2 adds a controlled activity binding for current dealt, kernel-playable,
natively admissible options from the existing deck selector, bounded to128.
Each binding identifies the exact card hash and target, with native steps and
current aliases. Existing generated human-goal cards are excluded. The compiler
selects an offered binding and reuses its original agenda/card/target and kernel
effects. It does not mint or translate a replacement card, fabricate verbs,
accept arbitrary parameters, or put original owner words into public cues.

The activity postcondition is registered_card_effects. It does not advertise
navigation arrival, sitting, consumed food or whole-purpose fulfilment merely
because a card was selected. Those original semantic goals keep their own native
postconditions. Native admission remains authoritative. Exact unique current
option aliases can be interpreted without a model; broader language still uses
the bounded registry compiler with its independent technical/no-action outcomes.
Named greeting/conversation recipients are checked, and a vanished/changed
binding is rechecked before publication. Sitting prohibitions also apply to
registered cards containing a native SIT step.

Four new fake/native cases pass: existing fire card enters the native campfire
controller with no replacement mint; greeting preserves Bob and creates its
original directed kernel speech effect; an intervening recipient retirement
refuses publication and preserves prior intentions; an injected model selecting
Claire for an explicitly named Bob greeting is refused. Existing five-goal/native,
private-authority and strict-schema regression15 pass. Types pass. No paid
provider calls. Speech evidence is the kernel speech act; dialogue generation
quality, live models, whole UI/native registry coverage and real accounts are
not qualified by these cases.

This expands strict private goal/owner-control data. App must consume the V2
advertisement and activity/registered_card_effects variants from matched schemas.
A named contract proposal and selected paired dependency packet must be reviewed
before activation. Old strict consumers/keepers must not read new activity
revisions after their first publication. The current Root remains its legacy V2
compiler with native retention; prior frozen packets are unchanged.

Newcomer resources, full actor repertoire/composition, literal dialogue and
long-term memory, real owner/agent qualification, budget and release gates
remain in the approved backlog.
