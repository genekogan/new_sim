# Recorded experience informs ordinary choices

The existing recorded episode policy protected reflective journals, but ordinary
choice still consumed recent semantic labels and journal prose alone. Under the
same explicit intentEpisodeMemoryV1 policy, ordinary private choice now receives
private-purpose-experiences/1: at most three own current-revision recorded attempt
outcomes, with original intent/version, admission/controller evidence and ticks.
The current world/Soul/body and observation frontier identify the viewpoint.

Selection considers the existing twelve recent owned episode records, preferring
those associated with the bounded recalled purposes, then recency. It does not
retrieve all past events or create a full memory index. Strict commitments retain
their separate full-or-overflow rule. Journal prose cannot create an episode;
admission remains distinct from physical start, and completed contributions do
not fulfil the broad purpose or prescribe an activity. No routine or FIFO is added.

The ordinary model request receives those records as owner_experiences. Its choice
instructions preserve the fact/interpretation boundary. The choice fingerprint
includes selected records, so meaningful experience changes request thought;
observation tick/frontier changes alone do not force repeated calls.

A pending choice captures the selected records. New own recorded evidence before
response acceptance drops that stale answer, even when owner will is unchanged.
The writer checks again before any prepared choice commits. This uses existing
stale-result handling and keeps the world progressing. Current owner/body/native
correspondence is required; foreign or changed ownership yields no memory packet.

Four new checks cover the actual canonical admission records, bounded private
context, synthetic delayed choice, writer-order race, public negatives and exact
snapshot/genesis reconstruction. Together with the three existing reflection
checks they pass seven; types pass. Generic timed-rest records in these fixtures
remain admitted evidence rather than invented physical start/completion. Synthetic
Jev transports and fake minds cost zero; no paid behavioral-quality claim follows.

No owner/agent REST/MCP or public take/API schema gains this field. Existing
perception responses stay unchanged; any future personal-memory read contract
needs paired consumer review. Current Root/defaults/main/live budget/history are
unchanged. This is an internal ordinary-choice connection to bounded source-backed
experience, not relationships, shared-project memory, a region/world atlas,
model quality, all-purpose coherence, a real-host/device or release qualification.
