# Ordered named targets and failure boundaries

The typed compiler's named-place check consumed the entire tail of a request as
one target, and required every bound goal to use that target. A request such as
“Go to the campfire, then sit on the north bench by the campfire” therefore could
not preserve its distinct registered destinations.

The check now recognizes explicit `then` boundaries before the existing action
words and checks each named target against the matching ordered goal. Registry
aliases and goal types remain authoritative. Reordered, omitted and substituted
targets are refused before publication; unknown names still require clarification.
This is bounded validation of the model's offered plan, not a general language
parser or new schedule/routine. Existing schema, owner fences, physical feasibility,
strictness, prohibitions and future/conditional checks remain in force. Historical
compiled plans are read from their recorded facts rather than recompiled.

An actual synthetic-owner compilation check accepts campfire→north-bench and
rest→north-bench, and rejects reversing, omitting or substituting a named step.
The existing closed-goal checks remain relevant to single destinations and safety.
A separate native fault check admits walk→owned-meal, removes the native bench
before lowering, and observes a genuine blocked controller outcome, progress0,
retained active purpose and untouched next meal. This deliberate ephemeral fault
is not logged as a world edit and qualifies no restart/reconstruction claim.
An execution-only historical keeper refuses the new paired mode without adding
completion policy, changing engine state, or appending facts.

Initial fixture failures are retained in `.e2e`: “west bench” was not an offered
alias in this particular fixture; removal after movement had already lowered did
not fail its resolved walk; the social test initially omitted its social fixture.
Corrections use an actual offered alias, failure before native lowering, and the
existing opt-in social factory/rule. No provider calls or living preview changes.
