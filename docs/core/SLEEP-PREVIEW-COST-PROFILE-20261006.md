# Native sleep preview cost, before optimization

An isolated real native sleeper stays on its canonical finite mat. Observational
wrappers time its live snapshot/hash reads, actual factory restore and detached
copy steps. The compiler uses a synthetic transport with real validation/card
minting; its returned revalidation closure is invoked directly. The world clock
is stopped after physical preparation. No live stop, movement, new programme
admission or provider call is made by the measurement.

Repeated safety reads each construct a detached engine and advance the same
43-tick safe rise. The revalidation checks both the prepared card and the current
binding, producing two detached restores in this fixture. These timings identify
local costs; they are not an end-to-end latency reduction or a production profile.
They include instrumentation and one synthetic actor/current geometry only.

Engine hash, actual sleep programme and fully prone pose remain exact afterward.
No private stop or accepted attempt is published, no native invariant violation
occurs, and paid cost is zero. The compiler may mint the permitted semantic card;
that is separate from movement/admission. The first fixture correctly returned
interpreter-closed because it quiesced before compiling. Removing that fixture
mistake yielded one passing profile and types0. Both attempts are retained.

No optimization, cache, physical rule or canonical grammar is introduced here.

writer/admission guard. Existing withFeasibilityRead explicitly bounds memoization
