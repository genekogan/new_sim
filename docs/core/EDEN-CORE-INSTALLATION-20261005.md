## Explicit installation selection

| Setting | Meaning |
|---|---|
|`ENABLE_EDEN_CORE=1`|Select this bootstrap for engineMars/worldEden only. Other worlds retain legacy paths.|
|`APPLY_EDEN_CREW_CHECKPOINT=1`|Authorize the already-qualified logged policy checkpoint when required.|
|`APPLY_EDEN_COMMONS_CHECKPOINT=1`|Authorize the existing guarded physical commons checkpoint when required.|

These are source-controlled candidate settings for an operator to configure after
review. They grant no production operation in this task. Without selection,
the normal main path remains legacy. Missing required apply flags refuse before
either checkpoint is written. Source preflight restores a detached exact native
snapshot and checks policy, physical preview and kernel collisions first. Busy,
unknown/old29/other physical profiles and station-carry gaps refuse.

Greenfield0, original Greenfieldcrew1, logged policy/commons histories, or a

## Controlled shutdown

Selected Eden refuses new HTTP input, closes public/private sockets and stops
new thought work. Brain's`quiesce()` stops new evaluate/reflect/compile/translate/
attune/speech/director/narrator/shot requests and its DB maintenance timer.
Already accepted work, including nested mint/deck publication, drains through
tracked promises. Pure accepted minting may finish. The clock and DB stay open;
a scoped sequencer pump also handles accepted writes when the clock is paused.
The existing IntentControl worker drain remains responsible for durable receipts.

Archive scheduling and backup timers stop; started archive uploads/backups settle
before the eligible checkpoint and DB close. Failed uploads retain local replay.
This supplies a controlled drain, not provider abort, force kill, pending-crash
reinterpretation or guaranteed shutdown deadline. A held provider can keep the
drain open; a clock/drain error leaves the DB open with an incomplete-shutdown
notice. Other-world legacy shutdown behavior remains its existing path.
