# Parity proof — Eden, Mars and Little Martians in the god-mode vocabulary

Gene (33 §9): *"you dont have to rebuild mars, eden, and lm worlds… prove to me that its just about
possible in principle, that we have an equivalent system in terms of expressiveness and complete
feature coverage."*

This page is that proof, in three parts:

1. **The coverage matrix** (below, generated): every feature family of the three worlds, marked
   *now* / *now (define)* / *via import* / *not yet*, with the vocabulary that expresses it, whether
   a Soul can use it today, and what closes each gap. A script reads every item of the source files
   (232 Eden places, 95 activity spots, the Mars camp manifest, the LM scene, the 40 Eden client
   kits) and fails if any item is unmapped or if a row names a def or generator that does not exist.
2. **Three demonstrator templates** (`worlds/templates/{eden-district,mars-camp,littlemartians-garden}.json`),
   each a representative piece of its world built only with god ops (genesis/1) from the library, so
   they load from the New-world dialog like any template.
3. **Side-by-side screenshots** of each demonstrator beside the same view of the original.

Regenerate the matrix: `node tools/god-skill/scripts/parity/matrix.mjs --write --check`.
Regenerate the templates: `node tools/god-skill/scripts/parity/templates.mjs` (see *Demonstrators*).

## What "composable" means here

- **now** — the library already has it (a `core/…` def or a generator with the right params);
  a god agent places it with `place` and the compiler validates it.
- **now (define)** — nothing in the library has this exact thing, but a `define` op of a small
  kit/2 def (≤ 96 rounded primitives, prop ≤ 400 tris) expresses it with the right components
  (e.g. a chess board with `boardGame`, a campfire with a `flame` role and `light`). No new code.
- **via import** — the original is a sculpted or scanned mesh; it comes in as a GLB through the
  asset store with its footprint (rooms, shafts). *In library* means L5 already imported it as a
  core def (the Ceramic Tower, the Minaret Temple, the six kin, the pack animals and plants).
- **not yet** — the vocabulary cannot express it today; the row names the lane or Stage-B item.

The **Souls** column is separate on purpose: expressiveness for the god is ahead of what Souls can
do with the result. Souls walk, enter, climb, sit, carry and pray in god-built worlds today (L8/L9);
using beds, books, instruments, venues and sports is B5, the place tree is B4, migration of the
three live worlds is B6 (eden4/31). R2 does not claim those.
